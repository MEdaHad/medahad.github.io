How I build agent systems

I've been building and operating multi-agent systems for over a year: orchestration, tool permissioning, evals and the monitoring that catches agents failing silently. Guardrails by design: least agency, deterministic paths before model calls, raw telemetry and logs never sent to a model unfiltered, and human approval on anything irreversible. The same thinking runs a support Discord bot: deterministic troubleshooting first, a Gemini knowledge base second.
