# Medhane Hadush Portfolio

This repository contains a one-page static portfolio for Medhane Hadush.

## Project Structure

```
medahad.github.io
├── index.html             # Single-file portfolio site (HTML, CSS, JS)
```

## How to View

1. Clone the repository.
2. Open `index.html` in a browser.
3. Or publish through GitHub Pages.
